# Server Inventory Configuration Manager 3.2.7

- Fixes the new header icon being blocked by the application's content policy. The application now permits its own local icon images while keeping remote images blocked.
- Includes the editable flat server/checkmark SVG and the same ten compiled Windows icon sizes introduced in 3.2.6.
- Adds a real-browser regression that reproduces the blocked-image failure, confirms the header SVG renders, and verifies remote images remain blocked before publication.

Download Server-Inventory-Configuration-Manager.svg for the editable vector artwork. Its named shapes and four solid colors can be edited without an embedded bitmap. The EXE, window, header and browser icons share the same design.

The original collectors, reports, configuration controls, window persistence, guest-session isolation and native updater behavior are preserved. The report-viewer content policy is unchanged. Updates remain explicit Download and Install and restart actions. Earlier release tags and assets, including 3.2.6, remain unchanged.
