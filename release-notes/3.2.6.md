# Server Inventory Configuration Manager 3.2.6

- Applies the new flat server-rack and inventory-checkmark icon to the executable, window, browser icon and application header.
- Includes a fully editable SVG with named vector shapes, four solid colors and a transparent background.
- Builds ten Windows icon sizes from that SVG and verifies the compiled executable's icon resources and native shell extraction.

Download the editable Server-Inventory-Configuration-Manager.svg and its checksum from this release. Source editing instructions and the original archived icon files are in the repository.

The original collectors, report generation/viewer and configuration controls are preserved. Window position/size persistence, private guest sessions and native updater behavior remain intact. Updates still require Download followed by Install and restart. Earlier tags and assets are unchanged.
