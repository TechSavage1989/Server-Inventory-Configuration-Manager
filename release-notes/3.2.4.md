# Server Inventory Configuration Manager 3.2.4

- Opens the interface in a dedicated guest app session with account sync and extensions disabled, preventing account extension restoration in the application session.
- Closes the old application browser during updates even if Edge has handed off to another process or a page dialog is open.
- Stops polling and focus requests before installation; update-action errors appear in the compact banner instead of repeated modal alerts.
- Adds regression tests against the actual previous interface and native browser, including old-process closure and guest-session verification.

The app does not change personal Edge/Chrome settings, extensions, accounts or machine policies. If policy blocks guest mode or requires browser sign-in, it reports that the isolated interface cannot open instead of falling back to a personal profile.

To update, choose Download, then Install and restart. If an earlier app already left windows open or shows account prompts, close those old app windows once and download this fixed EXE directly. Keep the executable at the same path to preserve existing shortcuts. Settings remain in per-user LocalAppData.

The v3.0.10 collectors, reports, viewer, configuration controls and icon are preserved. The Portable EXE header badge remains. Earlier tags and release assets are unchanged.
