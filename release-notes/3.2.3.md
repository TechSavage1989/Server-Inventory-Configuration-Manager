# Server Inventory Configuration Manager 3.2.3

- Adds a small Portable EXE badge in the application header so this update is easy to identify after installation.
- Advances the visible application and collector version to 3.2.3 for updater testing.

To test the update, start v3.2.2, choose Check for updates, then Download and Install and restart. Confirm that the application shows version 3.2.3 and the new Portable EXE badge.

The original inventory collectors, report generation/viewer, icon, and settings behavior are preserved. Updates remain explicit user actions. Older releases and assets are unchanged.
