# Server Inventory Configuration Manager 3.2.1

- Fixes update-feed encoding, cached status, and manual checks during server-requested backoff.
- Verifies exact Windows application metadata and requires a rendered interface plus a visible owned window after updating.
- Preserves the original v3.0.10 collectors, report viewer, configuration interface, and icon assets.
- Adds source provenance checks, native install tests, and a published v3.2.0-to-v3.2.1 upgrade test.
- Uses the stable portable filename Server-Inventory-Configuration-Manager.exe and keeps updater data under per-user LocalAppData.

The original v3.0.10 executable has no built-in updater. Download this executable once to enter the maintained executable release line. The existing v3.1.0 PS1 release is historical, unchanged, and cannot upgrade itself to the executable format. Its old latest-release URL now points to executable metadata; use the executable directly.

Updates require explicit Download and Install and restart actions. SHA-256 verifies bytes against the HTTPS release manifest; it does not establish publisher signing.

Windows CI evidence is published with the release. The post-publication Windows workflow tests the actual previous executable against the public feed. See DEVELOPMENT_HANDOFF.md and VALIDATION.md for the exact results and remaining manual Windows/UAC checks.
