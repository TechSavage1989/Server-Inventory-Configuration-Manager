# Server Inventory Configuration Manager 3.2.10

- Clearer setup with visible profile selection, searchable categories, a live scope summary and expandable configuration exports.
- Save and restore your output folder, inventory categories, safe exports and event-history window across application restarts.
- Search and filter execution logs, inspect earlier messages without scroll jumps, and resume live following when ready.
- Inline errors, keyboard tab navigation and smaller-window layouts make daily use easier.
- Corrected dependent category deselection and locked event-history settings during collection.

Use Save choices without starting a collection, or start collection to save the current choices. Sensitive-export permission and NPS full export must be selected again in each session. Choices are stored in per-user LocalAppData alongside existing settings, with a separate file so older rollback versions do not overwrite them.

The original collectors, HTML/Word/text reports, report viewer, icon artwork, isolated guest browser, native window placement and native updater remain in place. Existing output files are unchanged. This is a new executable version; no prior release or tag is replaced.

Application-Preview.png and Report-Preview.png use synthetic example data. The original editable Illustrator master and derived runtime SVG are also included, each with a checksum. SHA-256 verifies downloaded bytes; it is not publisher signing.
