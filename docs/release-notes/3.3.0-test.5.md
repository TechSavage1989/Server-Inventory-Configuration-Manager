# Server Inventory and Migration Manager 3.3.0-test.5

Fifth test build. It is offered only to installs that ticked Also offer test builds in Help > Settings > Updates; stable installs never see it. It contains everything in 3.3.0-test.4 plus the plan sync fixes going out in stable 3.2.41 and Copy out in the VM console.

**Highlights**

- A plan round that stopped part way no longer makes the next round read the whole disk, and Last sync shows how each disk was read (VDDK, datastore, export or Hyper-V change tracking) and why.
- In the VM console, Copy out reads text from the VM's screen or from a file in the VM, then puts it on your clipboard.
- Plans can sync every 5 or 10 minutes, and SQL Server and domain controller check failures show one line per server with the full error under Details.

**Migration plans**

- When VDDK is already set up and a VM with a virtual TPM still fails, the row offers Retry with VDDK and Open the VDDK log.
- The Tested step no longer lights up for a VM that was never tested, and the wave check's untested line offers I tested these.
- Plan fields this version does not know are kept when it saves, so stable, test and rollback versions can share the plans file.

**VM console**

- Copy out reads the screen with Windows text recognition on this computer, or reads a file in the VM through VMware Tools, the QEMU guest agent or PowerShell Direct. Nothing is installed in the VM.

**Requirements and limits**

- Same as 3.2.41: Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime. Copy out from the screen needs Windows text recognition on this computer.
- This is a test build. Copy out, a changed-block round after a stopped round and 5-minute rounds are covered by synthetic checks only and have not yet been tried against real VMs.
