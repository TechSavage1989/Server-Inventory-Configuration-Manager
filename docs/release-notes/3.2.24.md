# Server Inventory and Migration Manager 3.2.24

Collection fix release. Restore, migration, update validation and settings are unchanged.

**Highlights**

- Collections on servers running DHCP now finish: report generation no longer stops with "missing mandatory parameters: Columns".
- The DHCP section of the report now lists DHCP policies, scope statistics and server bindings with their own columns.
- A new automatic check reads the whole collector and fails the build if any report step leaves out a required value, so this kind of error cannot ship again.

**Details**

- The error came from three DHCP tables in the report that did not name their columns. They only run when the server has DHCP scopes, so collections on other servers were not affected.
- No other collection or export behavior changed. The DHCP data itself was always exported to the package; only the consolidated reports failed.
- Run the collection again on any DHCP server whose earlier collection failed.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated with the real report code and a static check of every collector call on hosted Windows. Not yet re-run against a live DHCP server.
