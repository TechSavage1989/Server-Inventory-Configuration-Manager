# Server Inventory Configuration Manager 3.2.0

- Restores the maintained product to the portable executable baseline, preserving the v3.0.10 inventory/reporting interface and collectors.
- Adds dependable startup, five-minute, and focus-return update checks with ETag caching, explicit offline/error states, Retry-After handling, and backoff.
- Adds explicit Download and Install and restart actions with HTTPS host allowlisting, size/SHA-256/PE/application identity/version validation, target-filesystem staging, atomic replacement, one-generation rollback, and healthy visible-start confirmation.
- Moves updater state, logs, downloads, health state, rollback data, and saved output settings into per-user LocalAppData.
- Removes unnecessary PowerShell ExecutionPolicy Bypass use from embedded collector execution and standardizes the stable release filename as Server-Inventory-Configuration-Manager.exe.
