# Server Inventory and Migration Manager 3.3.3-test.1

First test build after 3.3.2. Only installs with Also offer test builds ticked in Help > Settings > Updates are offered it; stable installs never see it. It has everything in stable 3.3.2, plus a test-only live server move in the Restore tab. Its number is above 3.3.2 so Test-channel installs on 3.3.0-test.5 move to it.

**Highlights**

- New Move SQL databases tool: reads both SQL Servers, suggests backup and restore, log shipping or a distributed availability group per database, carries logins, Agent jobs and linked servers, tests, cuts over and rolls back.
- Prepare this package for a new server lets the Restore tab put roles and features, local users and groups, file shares, IIS sites with their files and certificates, DNS and DHCP back working on a different server.
- Copies read ahead while they write, sending disks and physical-to-virtual conversion skip free space, and VDDK, receiver and file share transfers are compressed.

**Move SQL databases**

- Find it under Migration and replication, or pick SQL Server databases in New migration. Nothing is installed on either SQL Server.
- Each database gets a suggested method with the reason; distributed availability groups are offered only for databases already in an availability group, and standalone servers use log shipping.
- Logins keep their SIDs and passwords, Agent jobs are created turned off and turned on at cutover, and a DNS alias can follow the move.
- Roll back takes the new copy offline (never deleted) and makes the old database writable again.

**Restore onto a new server**

- Collection offers Prepare this package for a new server, which encrypts its secrets with a passphrase that is never saved.
- The Restore tab shows Changes for this server: old addresses and drive letters mapped to this server's, filled in and editable.
- New restore parts: roles and features, local users and groups, file shares; IIS gets website files, passwords and HTTPS bindings; certificates move with their private keys; accounts are mapped for permissions, security policy and scheduled tasks; more DNS zone types and DHCP authorization.

**Move a server live (test build only)**

- The Restore tab's Restore from: Another server, live reads the old server over PowerShell remoting into a migration package there, copies it to the new server with Robocopy (only changes on a second read), then checks and restores it inside the new server with the usual restore steps.
- Cutover stops the old server's IIS sites; Start them again is the way back; Finish removes both packages. Nothing is installed on either server, and the package passphrase is random and kept only in memory.
- New migration offers Windows server roles as a source, live from the old server or from a package, and hands off to the Restore tab.
- Not yet field-tested on two real servers.

**Faster copies**

- The copy engine reads and checks the next chunks while it writes the current one.
- Send disks and physical-to-virtual conversion skip free NTFS space instead of reading it.
- VDDK reads ask ESXi for compression, receivers and remote Hyper-V copies compress chunks, and file share copies use Robocopy compression where Windows supports it.

**Fixes**

- Details sections in Migration plans' wave check (and other screens that refresh themselves) stay open instead of closing a second later.
- A SQL and DC check that cannot reach a VM over WinRM no longer holds a wave for VMs whose names do not look like a domain controller or SQL Server; it is shown as a note.
- The README links the live demo and feature tour at the top.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- Linux replication, ReFS volumes and VMware copies made without VDDK still read all used data each round.
- Not yet field-tested: real SQL Server instances, availability groups and DNS alias moves; a full restore between two real servers; VDDK compression on real ESXi and Robocopy compression between real servers.
