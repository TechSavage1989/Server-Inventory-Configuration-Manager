# Server Inventory Configuration Manager 3.2.14

Report redesign and small-screen release. Inventory collectors, collected data, Word/text output, update validation and settings are unchanged.

**Highlights**

- Redesigned HTML report: an executive summary with server profile, collection health and a Needs attention panel, and section pages grouped under their headings instead of one long list.
- The application stays usable on 800x600 and 1024x768 screens: a compact layout keeps the settings, the collection log and the report within reach.
- The update bar appears only when an update is available. Check for updates, keyboard shortcuts and version details are under the new Help menu.

**Application**

- **Help** menu in the top bar with **Check for updates…**, **Keyboard shortcuts** and **About**. The About and updates dialog shows the installed versions, the update status and the time of the last check. Automatic checks are unchanged, and nothing is downloaded or installed until you choose to.
- **Open output folder**, **Show ZIP archive** and the other folder buttons bring the folder window to the front instead of leaving it behind the application.
- Compact layout at window heights of 720 px or less; panels scroll instead of clipping, and no text is smaller than 11 px.

**Report**

- Summary tiles, health figures and detected-role chips link to their datasets.
- Larger sections start with a contents panel showing row counts and items to review. Empty datasets fold into one "No data collected" group per section and remain searchable, copyable and printable.
- Name/value tables read as property sheets; tables with failures or warnings show how many rows to review; the navigation highlights the subsection being read.
- The report stays legible in small windows, standalone and inside the Report Viewer. Existing reports remain readable; generate a new report to get the new layout.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated on hosted Windows with Edge and synthetic data. Bringing folder windows to the front has an automated Windows check but has not been confirmed by hand on a physical desktop or on Windows Server 2012 R2.
