# Server Inventory and Migration Manager 3.2.27

Collector fix release. Reports, restore, migration, update validation and settings are unchanged.

**Highlights**

- The Active Directory health and topology collector no longer fails on domain controllers with "The format of the specified domain name is invalid".
- The recent System and Application event history collector no longer fails with "Cannot run a document in the middle of a pipeline" on servers that have a stray file named Get-WinEvent.
- Both collectors now finish and save their exports, so the report lists no failures for them.

**Details**

- The AD collector now passes the forest name when it collects forest-wide replication failures. It previously passed "*", which Windows rejects. Its other AD exports were already saved before this step.
- The event history collector now calls Get-WinEvent by its full module name, so a file with the same name in a PATH folder such as C:\Windows\System32 can no longer take its place. Review and remove such a file if it is not needed.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- A matching SHA-256 is integrity validation, not publisher signing.
- The event history fix is reproduced and verified on hosted Windows with a Get-WinEvent file on PATH. The AD fix has not been run on a domain controller, because hosted runners are not domain controllers.
