# Server Inventory Configuration Manager 3.2.2

- Cleans temporary update files when an installed executable is locked or unreadable.
- Keeps the installed EXE unchanged when a safe rollback copy cannot be prepared, with a useful failure notice.
- Adds a Windows regression test against the actual published v3.2.1 EXE, demonstrating the former cleanup failure and the fix.
- Retains the complete executable updater, original v3.0.10 collectors/interface/report viewer/icons, stable filename, native rollback, and rendered visible healthy-start confirmation.

Download and Install and restart remain separate explicit actions. No update is automatically downloaded, installed, or restarted. Settings, update data, logs, staging, and rollback remain under per-user LocalAppData.

The original v3.0.10 EXE has no built-in updater. Download Server-Inventory-Configuration-Manager.exe once to enter the maintained executable line. The historical v3.1.0 PS1 release, v3.2.0 executable, and v3.2.1 executable remain unchanged. The PS1 updater cannot change application formats; its old shared latest-release URL now serves executable metadata.

SHA-256 validates bytes against the HTTPS release manifest; it is not proof of publisher signing. See DEVELOPMENT_HANDOFF.md and VALIDATION.md for exact hosted Windows results, the real published v3.2.1-to-v3.2.2 upgrade test, and remaining UAC/physical desktop limits.
