# Server Inventory Configuration Manager 3.2.16

Report follow-up release based on feedback on 3.2.15. Inventory collectors, collected data, Word/text output, update validation and settings are unchanged.

**Highlights**

- A report table with problems now shows errors and warnings buttons in its header.
- Click one to jump straight to the affected row, even in tables with hundreds of rows.
- Click again to move to the next affected row.

**Details**

- The red **errors** button covers failed and high-severity rows; the amber **warnings** button covers warning, unavailable and skipped rows.
- A click opens the table if it is collapsed, clears its row filter so the row cannot be hidden, and highlights the row. It never collapses the table.
- Existing reports remain readable; generate a new report to get the buttons.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated on hosted Windows with Edge and synthetic data, not on a physical desktop or Windows Server 2012 R2.
