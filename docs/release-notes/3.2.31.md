# Server Inventory and Migration Manager 3.2.31

VMware relationships release. After reading vCenter or ESXi, the VMware tab and the discovery report show which VMs run on each host, which VM disks live on each datastore and which VMs use each network. Collection, reports, restore, file share migration, update validation and settings are otherwise unchanged.

**Highlights**

- Browse hosts, datastores and networks in the VMware tab: group by cluster and host, datastore or network, expand each to see its VMs, disks and adapters, and search across all of them.
- The VMware discovery report lists each host's VMs, each datastore's mounting hosts and VM disks, and each network's VMs, all linked to each other.
- Each datastore now records the hosts that mount it.

**Details**

- Choosing a VM in the browse panel shows its readiness and details above.
- Datastores show a usage bar, free space, the number of VMs and disks, and each disk's file path.
- Raw device mappings and disks on datastores the account could not read are listed separately.
- VM-Disks.csv and VM-Network-Adapters.csv gain Host and Cluster columns at the end; Datastores.csv gains the mounting hosts and the datastore URL.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- Read vCenter or ESXi again to see datastore mounts; inventories saved by earlier versions show VMs and disks but not which hosts mount each datastore.
- Disks are still not converted or copied; use the usual tool for your platform.
