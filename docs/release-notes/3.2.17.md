# Server Inventory Configuration Manager 3.2.17

Built-in window release for company-managed PCs. Inventory collectors, collected data, reports, update validation and settings are unchanged.

**Highlights**

- When company policy turns off guest browsing, the application now opens in its own built-in window instead of stopping.
- The built-in window uses Microsoft Edge WebView2 and never opens your personal browser profile or changes browser policy.
- When the application cannot open at all, the message now names the exact reason, including the blocking policy.

**Details**

- The private Edge or Chrome guest window is still used first wherever it is allowed. The built-in window is used when guest browsing is blocked or no supported browser is installed.
- The built-in window remembers its size and position, shows collection progress in its title and closes the application when closed. Right-click Copy works; developer tools are off.
- It needs the Microsoft Edge WebView2 Runtime, which is part of Windows 10 and 11. On Windows Server 2012 to 2019 it is a separate free install from Microsoft.
- Edge and Chrome installed outside the standard folders are now found through their Windows registration.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated on hosted Windows with Edge, WebView2 and synthetic data, including a real per-user policy that blocks guest browsing. Not yet validated on a company-managed PC or on Windows Server 2012 R2.
