# Server Inventory Configuration Manager 3.2.8

- Applies the new flat server/checkmark icon to existing desktop shortcuts and refreshes the executable icon in Windows Explorer.
- Keeps desktop icon files in persistent per-user application data so closing the application does not remove them. Existing shortcut targets and launch settings are preserved.
- Uses native Windows shell notifications and shortcut APIs without restarting Explorer, deleting global icon caches or opening prompts.

The same approved icon remains compiled into the EXE and used by the window, header and browser icons. The editable SVG is included with its checksum. Shared desktop and portable-folder shortcuts use the embedded EXE icon so they remain readable across users. Only shortcuts targeting this executable are updated.

Inventory collection, reports, configuration controls, guest isolation, remembered window size/position and secure native updates are preserved. Download and Install and restart remain separate explicit actions. Prior releases and tags are unchanged.
