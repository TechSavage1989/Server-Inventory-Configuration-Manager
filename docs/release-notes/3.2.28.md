# Server Inventory and Migration Manager 3.2.28

VMware migration release. A new VMware tab helps move VMs from VMware or ESXi to Hyper-V or Scale Computing HyperCore. Collection, reports, restore, file share migration, update validation and settings are unchanged.

**Highlights**

- New VMware tab (Alt+6) reads a vCenter or ESXi host read-only and marks every VM Ready, Review first or Blocked for Hyper-V and for HyperCore, with the actions to take.
- Plan cluster sizing, network and datastore mapping and migration waves, then write a runbook and plan CSV for the team.
- Run on a Windows VM before and after cutover to put static IPs back on the new adapters, clean up hidden old adapters, bring data disks online and remove VMware Tools, and compare two collections to see what changed.

**Details**

- Environment: connect with a vCenter or ESXi account. Nothing in vSphere is changed. The password stays in memory until you choose Forget or close the app, and an untrusted certificate is accepted only after you trust its exact thumbprint. The inventory, a readiness report and CSVs are saved in the output folder, and a saved inventory can be opened again later.
- Plan and runbook: enter the target cluster size and reserve, map each port group and datastore, and assign VMs to waves (or use Suggest waves). The plan is saved per server so you can come back to it.
- This VM: Capture records the VM's IP settings, disks, drivers and services before the move. After cutover, Apply restores the IP settings to the new adapters, with Undo. Steps that change the VM need its computer name typed to confirm. VMware Tools is not removed while the VM is still on VMware, and boot and system disks are never touched.
- Before and after: compare two collection packages (folders or ZIPs). Changes expected from a move, such as VMware Tools, network adapters and drivers, are listed apart from changes to check. The comparison is written outside both packages.
- The executable is larger (about 20 MB) because it now includes the VMware client library.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- A matching SHA-256 is integrity validation, not publisher signing.
- Disks are not converted; use your usual conversion or migration tool. The VMware reader is tested against VMware's vCenter and ESXi simulator, not yet a live vCenter. The VM fix-up is tested on hosted Windows with a loopback adapter; removing hidden adapters and VMware Tools is covered only by refusal checks, because hosted runners have no VMware hardware.
