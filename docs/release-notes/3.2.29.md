# Server Inventory and Migration Manager 3.2.29

Migration targets release. The VMware tab now plans moves to Nutanix AHV, Proxmox VE, Microsoft Azure, Amazon EC2 and physical servers, as well as Hyper-V and Scale Computing HyperCore. The Migrate tab is now called File shares. Collection, reports, restore, file share migration, update validation and settings are otherwise unchanged.

**Highlights**

- Choose Nutanix AHV, Proxmox VE, Azure, Amazon EC2 or a physical server (V2P) under Moving to, alongside Hyper-V and Scale HyperCore; readiness, sizing and the runbook follow the choice.
- This VM names the platform a Windows computer runs on now and checks the drivers the chosen target needs, so it also helps with moves from other platforms.
- The Migrate tab is now labelled File shares, since that is what it moves.

**Details**

- New readiness rules per target: VirtIO drivers for Nutanix and Proxmox, ENA and NVMe drivers for EC2, Azure disk size limits, BIOS firmware and vendor drivers for physical servers, and each target's own guidance for Secure Boot, virtual TPM, shared disks, passthrough and USB devices.
- Azure and EC2 are sized against your subscription or account quota instead of a cluster; physical targets list what each server needs.
- The readiness report and VMs.csv show readiness for every target side by side.
- Before and after comparison treats Nutanix, AWS and Azure guest agents and drivers as expected changes.
- The release executable is now signed with Azure Artifact Signing when the release workflow's signing secrets are set.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- Disks are still not converted or copied; use the usual tool for your platform. The new targets' rules come from vendor documentation, and platform detection has not yet run on Nutanix, Proxmox or EC2.
