# Server Inventory Configuration Manager 3.2.18

Restore release. Inventory collectors, collected data, reports, update validation and settings are unchanged.

**Highlights**

- A new Restore tab puts configuration from an inventory package back onto a server, one checked item at a time.
- It restores DHCP, NPS, printers and print drivers, IIS, DNS zones, Group Policy, firewall, certificates, scheduled tasks, share permissions, registry settings and local security policy.
- Before each item changes, its current configuration is saved to a rollback folder, and nothing runs until you review the plan and type the server name.

**Details**

- Choose the latest collection, the loaded report's package, or browse to a package folder. Every file is checked against the package's SHA256-Manifest.csv and checked again when the restore starts; a file changed after collection is never used.
- Each component shows what it would restore, or exactly why it cannot (for example the role is not installed, or the export was not selected when the package was collected), with its warnings. Group Policy and registry items are never selected by default.
- Restoring needs administrator rights. Items run in a fixed order and the restore stops at the first failure. Stop after current item never interrupts an item part way through. Collection, updates and closing the app wait until a restore finishes.
- On Windows Server 2016 and later, DHCP scopes, leases, reservations, server options, classes and option definitions are restored. Network Access Protection settings are left out because those Windows versions no longer support them, and server-level DHCP policies, filters, failover and DHCPv6 are listed for you to re-create.
- Device drivers other than print drivers, Active Directory, SQL Server, RRAS, AD CS and Hyper-V are not restored. Private keys were never exported, so certificates that need one must come from a protected PFX.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime. Restoring needs administrator rights.
- A matching SHA-256 is integrity validation, not publisher signing.
- Restore was validated with real round trips on hosted Windows Server 2025 with the DHCP, DNS, IIS, NPS and Print Server roles and synthetic data. Group Policy restore, restoring onto a different server, and Windows Server 2012 and 2012 R2 have not been validated.
