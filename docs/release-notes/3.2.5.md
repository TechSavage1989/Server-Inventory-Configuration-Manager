# Server Inventory Configuration Manager 3.2.5

- Remembers the application's last window position and size across close/reopen and updates.
- Remembers maximized state and preserves normal restore bounds. Closing while minimized reopens the last usable window state.
- Recovers saved positions that are outside the current display layout and keeps window state separate from inventory settings and temporary guest profiles.

The v3.2.4 guest session, disabled account sync/extensions, updater shutdown fixes, existing collectors, reports, viewer, controls and icon are preserved. Updates still require Download followed by Install and restart. Earlier tags and assets remain unchanged.
