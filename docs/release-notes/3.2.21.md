# Server Inventory and Migration Manager 3.2.21

Report and migration fix release. Collection scope, restore, update validation and settings are unchanged.

**Highlights**

- The report's executive summary server profile now shows Windows activation status.
- It also shows TCP/IP details: IPv4 addresses, default gateway and DNS servers, plus DHCP or static addressing and IPv6 addresses when present.
- The same details are added to the Server identity and baseline table in the HTML, Word and text reports.

**Details**

- Activation status names the license state (for example Licensed, or a grace period with the days left) and the Windows edition.
- Addresses include their prefix length and network adapter. Loopback, self-assigned (169.254.x.x) and link-local addresses are left out.
- The values come from data every collection already gathers, including on older servers that use the WMI fallbacks. Fields with nothing to report say None found or Not collected.
- Existing reports are unchanged; collect again to get the new profile fields.
- Migrate: Connect now reaches the old server over WinRM first, then over DCOM with packet privacy, which fixes Access is denied from servers that enforce DCOM hardening.
- Migrate: when the old server still refuses access, the message says to use an account that is an administrator on the old server (a local account with the same name and password loses administrator rights over the network), and otherwise names the WinRM and WMI firewall settings to check.
- The first start of the interface now has a three-minute grace period before idle shutdown, so a slow first WebView2 start no longer closes the application.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated with synthetic saved exports and the real report renderer on hosted Windows. Not yet checked against a live collection on Windows Server 2012 or 2012 R2.
