# Server Inventory and Migration Manager 3.3.0

Everything tested in the 3.3.0 test builds is now in the stable release: a simpler migration interface with a status track for every VM, VM consoles inside the app for every platform, and everything in 3.2.41.

**Highlights**

- The migration screens are simpler: a status track with the next step for every VM, plain-language explanations with fix buttons beside each error, and a wave-by-wave Ready to cut over check.
- Open a VM's console from the app for VMware, Hyper-V, Proxmox VE, Nutanix AHV and Scale HyperCore, with special keys, paste as typing (Ctrl+V) and Copy out of text from the screen or a file in the VM.
- Includes every fix of 3.2.41: VDDK copies of running VMs, Sync now that always answers, visible changed-block reads, 5-minute syncs and optional remembered sign-ins.

**Migration interface**

- Tool lists show each tool's name and one line; where it runs, what it works with and when to pick it are under About this tool.
- New migration has a sortable VM table, step summaries you can click to go back, saved defaults per customer and a rolling conversion option for VMware hosts converted to Hyper-V one at a time.
- Discovery can start a migration with the VMs it shows. An activity strip under the tabs counts what is moving now on every screen.
- Migration plans show a Ready to cut over check per wave (copies, failures, tests, recent syncs and SQL Server or domain controller findings), the Tested step lights up only after a test, and I tested these records tests made elsewhere.
- Ticking or unticking VMs and servers no longer moves the controls around them.

**VM consoles**

- One console window for every platform, opened from VM pages, migration plan rows, All jobs and servers, New migration and Start VMs from copies. It has no power controls.
- Hyper-V consoles go through the host's own WMI interface with the signed Connect-HyperVConsole.ps1 script; nothing is installed on the host or in the VM.
- Ctrl+V or Shift+Insert types the clipboard into the VM, and Ctrl+Shift+V sends a plain Ctrl+V.
- Copy out reads the screen with Windows text recognition on this computer, or reads a file in the VM through VMware Tools, the QEMU guest agent or PowerShell Direct.

**Updates**

- Installs on the Test channel are offered 3.3.0 as well; the channel setting in Help > Settings is unchanged.
- Plan fields one version does not know are kept when another saves, so stable, test and rollback versions can share the plans file.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime. Copy out from the screen needs Windows text recognition on this computer.
- The new interface is covered by synthetic checks. The VM consoles, Copy out and paste have not yet been tried against real vCenter, Hyper-V, Proxmox VE, Prism and HyperCore hosts, and the limits listed for 3.2.41 still apply.
