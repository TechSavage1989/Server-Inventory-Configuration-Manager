# Server Inventory and Migration Manager 3.3.0-test.2

Second test build. It is offered only to installs that ticked Also offer test builds in Help > Settings > Updates; stable installs never see it. It contains everything in 3.3.0-test.1 plus the fixes of stable 3.2.40.

**Highlights**

- Help > Settings accepts genuine Broadcom VDDK folders again: each DLL's embedded signature and the vixDiskLib version are checked from the files themselves (from 3.2.40).
- Ticking or unticking VMs and servers no longer moves the controls around them, and hints that only said how to use a control are gone.
- To go back to stable builds, untick Also offer test builds in Help > Settings > Updates; the newest stable release (3.2.40) is then offered.

**Changes since 3.3.0-test.1**

- VDDK: a folder whose files are not signed by Broadcom or VMware, or are older than 7.0.3, is still refused, now with every reason given.
- The VM list's Migrate selected VMs button keeps one label and stays in place, turned off until VMs are ticked.

**Requirements and limits**

- Same as 3.2.40: Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- This is a test build. The new interface is covered by synthetic checks only, and the VM consoles have not yet been tried against real vCenter, Hyper-V, Proxmox VE, Prism and HyperCore hosts.
