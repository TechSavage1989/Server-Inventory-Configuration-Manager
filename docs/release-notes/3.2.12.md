# Server Inventory Configuration Manager 3.2.12

- Makes HTML inventory tables compact by default, with horizontal scrolling instead of forced wrapping. Optional wrapping remains available for longer values.
- Adds copy controls for tables, raw text, sections and the full report; individual values remain directly selectable. Copied text preserves complete reported values. A selectable manual-copy panel remains available when browser clipboard permissions prevent automatic copying.
- Adds table filtering and sorting without discarding captured rows. Copying a dataset retains every reported row, including rows hidden by its filter.
- Preserves actual array/list values in CSV-backed reports instead of PowerShell type labels such as `System.String[]`. Original typed CLIXML exports remain unchanged; existing safety-limit notices remain explicit.
- Speeds up final HTML and Word generation by avoiding redundant conversions and general-purpose formatting calls for already-normalized table cells. Synthetic output parity tests preserve cell text and Word document XML.
- Preserves the established collection workspace, updater safeguards, icons, settings, portable executable name, startup cycle guard and bounded recursive ACL exports.

The report changes apply to newly generated reports. Existing exported HTML remains readable and is not rewritten. Values already lost as type labels in old CSV/HTML require a fresh collection; reopening those files cannot recover them. Existing source snapshot limits still apply; full source values remain in the supporting exports where indicated. Clipboard availability depends on browser/security settings, with manual selection as the fallback.

Performance measurements use synthetic data on Linux PowerShell 7.4.13, not the user's Windows server. They do not measure inventory collection, package compression or network/filesystem delays. Hosted Windows validation and upgrade results are recorded separately; no live customer inventory is included.
