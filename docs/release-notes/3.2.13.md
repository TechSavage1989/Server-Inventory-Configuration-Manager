# Server Inventory Configuration Manager 3.2.13

Interface and report-viewer usability release. Inventory collectors, collected data, Word/text output, the updater and settings are unchanged.

**Collection workspace**

- Groups the 34 inventory categories into five labelled groups (platform, workloads, identity and network roles, file/print/backup, security and diagnostics) with per-group counts and one-click Select all / Clear group. Clearing a group also clears its dependent exports.
- Tags categories whose configuration export is enabled with **+ export**, and hides empty groups while searching.
- Adds **Revert to saved** for unsaved collection choices. Sensitive-export consent and NPS full export are still never remembered.
- The execution log filter shows live warning and error counts. **Next issue** (or `N`) steps through warnings and errors, the Warnings/Errors tiles filter the log, and **Copy** copies the messages currently shown.
- Update release notes in the update banner show their bullet markers again.
- After a run, **Open output folder** and **Show ZIP archive** go straight to the package.
- The window title shows progress and the outcome (for example `42% Collecting`), so a run can be followed from the taskbar.
- Keyboard shortcuts, listed under `?`: `Alt+1/2/3` switch tabs, `/` or `Ctrl+K` focuses search, `Ctrl+S` saves choices and `Ctrl+Enter` starts collection. In Report Viewer search, `Enter` / `Shift+Enter` / `F3` move between matches and `Esc` clears.

**HTML report**

- The section menu shows a badge counting failed, high-severity and warning items in each section.
- Numeric columns are right-aligned and empty datasets are dimmed.
- Report search: pressing `Enter` again moves to the next match, `Shift+Enter` goes back, `Esc` clears, and the status names the section containing the match. `[` / `]` move between sections and `/` focuses search.
- **Print section** prints only the current section with all of its datasets expanded, alongside Print all.
- A **Back to top** button appears on long sections.

The report changes apply to newly generated reports. Existing exported HTML remains readable and is not rewritten. Badges, alignment and dimming are presentation only; cell values, copied text and print completeness are unchanged.

Validation uses synthetic data on hosted Windows/Edge and real report generation without live server collection. No customer inventory is included.
