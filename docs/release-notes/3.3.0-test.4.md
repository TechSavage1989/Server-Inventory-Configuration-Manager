# Server Inventory and Migration Manager 3.3.0-test.4

Fourth test build. It is offered only to installs that ticked Also offer test builds in Help > Settings > Updates; stable installs never see it. It contains everything in 3.3.0-test.3 plus the fixes going out in stable 3.2.41 and paste into the VM console.

**Highlights**

- VDDK copies of running VMs now work: the application lets VDDK load its own plugins, which fixes error 16053 when a round started VDDK.
- In the VM console, Ctrl+V or Shift+Insert types the clipboard into the VM, and Ctrl+Shift+V sends a plain Ctrl+V.
- Migration plans can be saved while another plan copies, Discovery's connection sections fold into one line once an inventory is open, and Show why stays open in New migration.

**VDDK and errors**

- Help > Settings names any DLL a VDDK folder needs that is missing, and points to the Visual C++ 2015-2022 x64 runtime when that is what is missing.
- VixDiskLib's own messages are written to VMware\VDDK\Temp\vddk.log, and a VDDK failure names the step that failed and that log.
- Long errors in Migration plans, All jobs and servers and the transfer list show one line with a Details link that stays open across refreshes.

**Guest administrator account**

- The button no longer overlaps the password box, one click or Enter is enough, the name is filled in, and the password is remembered when Remember sign-ins is on.

**Requirements and limits**

- Same as 3.2.41: Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- This is a test build. Console paste and the VDDK log are covered by synthetic checks only and have not yet been tried against a real VM and VDDK.
