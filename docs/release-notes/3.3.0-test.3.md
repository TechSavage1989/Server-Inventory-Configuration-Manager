# Server Inventory and Migration Manager 3.3.0-test.3

Third test build. It is offered only to installs that ticked Also offer test builds in Help > Settings > Updates; stable installs never see it. It contains everything in 3.3.0-test.2 plus clearer syncing in migration plans and an optional remembered vCenter sign-in.

**Highlights**

- Sync all now and Sync selected now always say what they queued, what they left alone and why a plan is waiting, and a plan waiting for its vCenter sign-in offers Sign in and sync right there.
- A VM or server whose copy round is running shows Syncing with its progress in All jobs and servers, instead of In sync or Behind.
- Optional, off by default: Help > Settings can remember vCenter and ESXi sign-ins (sealed for your Windows account) so migration plans sign in again by themselves after a restart or update.

**Migration plans**

- VMs you ask to sync now are copied ahead of the plan's start time.
- A remembered sign-in never replaces a session or inventory you opened yourself. Forget, or unticking the setting, removes it, and a remembered password vCenter refuses is forgotten at once with a notice.

**Requirements and limits**

- Same as 3.2.40: Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later, or the WebView2 Runtime.
- This is a test build. The new interface is covered by synthetic checks only, and remembered sign-ins have not yet been tried against a real vCenter across a restart.
