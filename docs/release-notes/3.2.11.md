# Server Inventory Configuration Manager 3.2.11

- Preserves collection identity when formatting report properties, allowing the existing cycle guard to handle the startup cyclic-table snapshot instead of PowerShell enumerating it first. The synthetic startup probe now passes on the affected Server 2019 / PowerShell 5.1.17763.9121 / CLR 4.8.4811.0 host, including the original failing cyclic table snapshot.
- Shows the current share, elapsed time, and configured limit during recursive permission exports. Heartbeats describe activity, not a percentage of files traversed.
- Limits each owned ICACLS export to 120 seconds by default, configurable from 30 to 3600 seconds. Skip remaining recursive exports and whole-collection Cancel remain available.
- Keeps timed-out, skipped, failed, or interrupted exports explicitly incomplete; only successful nonempty ACL files receive the complete filename. Reports expose incomplete export results.
- Preserves the existing application layout, original collector provenance outside reviewed changes, report styling, updater, icons, and portable executable name.

The time limit covers the recursive ICACLS worker and bounded cleanup, not every inventory command or synchronous remote-filesystem operation. Earlier SMB queries or output-folder I/O may still wait; Cancel remains available. Validation uses synthetic data; no customer inventory is included. Older Windows Server/runtime combinations still require field confirmation.
