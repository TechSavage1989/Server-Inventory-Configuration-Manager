# Server Inventory Configuration Manager 3.2.15

Report follow-up release based on feedback on 3.2.14. Inventory collectors, collected data, Word/text output, update validation and settings are unchanged.

**Highlights**

- The HTML report now uses the full window width, so wide tables no longer wrap beside empty margins.
- Hover any value in the report and choose Copy to copy just that value.
- The Report Viewer shows Copy path next to the loaded report's file location.

**Details**

- The single-value **Copy** control appears for table cells and server-profile values when using a mouse. **Copy table**, **Copy section**, **Copy full report** and text selection work as before and remain the keyboard routes.
- Existing reports remain readable; generate a new report to get the full-width layout and the value copy control.

**Requirements and limits**

- Windows x64, Windows Server 2012 or later, with Microsoft Edge or Chrome 109 or later.
- A matching SHA-256 is integrity validation, not publisher signing.
- Validated on hosted Windows with Edge and synthetic data, not on a physical desktop or Windows Server 2012 R2.
