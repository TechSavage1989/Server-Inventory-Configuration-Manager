# Server Inventory Configuration Manager 3.1.0

- Establishes the public repository as the maintained source and release feed.
- Adds dependable background update checks after startup, every five minutes, and after returning to the app.
- Adds explicit Download and Install and restart actions with SHA-256 verification, identity/version checks, rollback, and healthy-start validation.
- Moves settings, updater state, logs, downloads, staging, health state, and rollback data into per-user LocalAppData.
- Adds Windows CI, release-manifest generation, public release verification, AGENTS.md, and DEVELOPMENT_HANDOFF.md.
